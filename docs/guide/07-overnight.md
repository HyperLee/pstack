# 長時間任務與恢復

先建立可驗證的信任，再擴大任務。

```text
$poteto-mode 持續修復這個匯出問題，直到指定 fixture 全部正確且相關測試通過。記錄每次假設與結果；這次不推送或合併。
```

長任務需要完成條件、範圍、預算與可用環境。主代理使用目前任務內的 watcher／事件等待，不假定存在 Cursor `/loop`，也不保證電腦休眠或關機後仍會執行。

```mermaid
flowchart LR
    A[提出假設] --> B[最小改動]
    B --> C[實際驗證]
    C --> D[保留或退回自己的改動]
    D --> E[記錄證據]
    E --> A
```

## 回來時如何審查

[`show-me-your-work`](../../skills/show-me-your-work/SKILL.md) 以 TSV 記錄決策、理由、證據與結果。檢查真正檔案與指令結果，不只讀代理摘要。可取得歷史時對照歷史；無法取得時標示證據缺口。

`$ketchup` 提供目前聊天中自上次使用者訊息後的變更與待決事項。它不是另一個會順便修改產品的任務。

## PR 佇列與暫停

Autopilot-stack 將指定工作做到可驗證、可供人審查，不合併。Autopilot-full 只有在明確取得相應授權後，才處理固定佇列的合併，每個 PR 仍要經獨立驗證。

需要停止時直接說明。Pause safely 會將停止要求傳給 workers，保留修改與證據，停止自己擁有的程序，留下 resume note。恢復時從實際狀態接續。

某個 PR 的監看留在目前任務。真正定期的工作才考慮另行建立 automation，且要有明確要求與實際輸入來源。
