# Investigation

Read the [Codex runtime contract](../references/codex-runtime.md) before using tools.

1. Keep the task read-only. Restate the question, scope and decision it should inform.
2. Trace actual ownership, data flow and callers. Use **how** for behavior and **why** for the historical record. Delegate independent source slices when useful.
3. Gather the closest available runtime evidence without changing product state. Distinguish observed facts, source-based inference and unknowns.
4. Return a cited explanation, alternatives when relevant, and the evidence needed before a fix. Do not run Opening a PR for an investigation.
