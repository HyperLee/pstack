# Multi-phase plan

Read the [Codex runtime contract](../references/codex-runtime.md) before using tools.

1. State goal, contract, constraints and evidence of completion. Inspect the repository to resolve discoverable facts.
2. Settle material design choices with source/evidence and permitted scratch probes. Honor Plan mode; do not implement a plan while asked only to plan.
3. Sequence small independently verifiable units by dependencies and risk. Name interfaces, concrete checks and the artifacts each phase hands to the next.
4. Return the decision-complete plan and assumptions. Implementation starts only after the user requests it.
