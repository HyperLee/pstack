# Prompting pstack in Codex

State the goal, a pass/fail done condition, useful current evidence and real constraints. Choose `$poteto-mode` for nontrivial engineering work; name a narrower skill when its specific result is wanted.

```text
$poteto-mode Export repeats rows after a retry. Reproduce first, fix the root cause, and show before/after row counts. Do not open a PR yet.
```

For a read-only investigation say so. For parallel work name independent slices and expected checks; the coordinator uses actual available capacity. For a long run name its finish condition, budget and authorized external actions. A request to keep working is not permission to merge, message others or change machine exposure.
